Sized for the Pixel 10 (1080 × 2424). The clock sits in the top third of the lock screen, so the number is placed lower. Wallpapers are still images: open this app and share or download again when you want the count to refresh.

How to set it as your Pixel lock screen
  1. Share image → pick Photos (or Download PNG, which lands in Files → Downloads).
  2. Long-press an empty spot on your home screen → Wallpaper & style.
  3. Tap Lock screen → More wallpapers → My photos and pick the image.
  4. Choose Lock screen only when it asks where to apply it. Skip any effects or zoom so the number stays where it was designed to be.
  5. To refresh the count: open Sol-1, tap Share or Download, and set it again. Two taps a day is a good check-in ritual.
  • In Chrome, tap ⋮ → Add to Home screen (or use the Install button above) so this opens like an app, offline too.
  • Your data never leaves the phone. Use Export below to back it up.
